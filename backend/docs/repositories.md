# Repositories Documentation

Spring Data JPA repositories for all entities:

- **StudentRepository**: CRUD for Student
- **UserRepository**: CRUD for User
- **CompanyRepository**: CRUD for Company
- **PlacementDriveRepository**: CRUD for PlacementDrive
- **ShortlistRepository**: CRUD for Shortlist
- **NotificationRepository**: CRUD for Notification
- **AuditLogRepository**: CRUD for AuditLog
- **LeetCodeStatsRepository**: CRUD for LeetCodeStats
- **RoleRepository**: CRUD for Role (enum, limited use)
- **ShortlistStatusRepository**: CRUD for ShortlistStatus (enum, limited use)

All repositories extend JpaRepository and provide standard database operations.
