# Entities Documentation

## Student
- Stores all student data: personal, academic, placement, offers, LeetCode stats, etc.

## User
- Represents system users (students, faculty, placement head).

## Company
- Details of companies visiting for placement drives.

## PlacementDrive
- Information about placement events and drives.

## Shortlist
- Tracks student shortlisting for drives.

## Notification
- Stores notifications/reminders sent to users.

## AuditLog
- Logs critical admin actions for accountability.

## LeetCodeStats
- Tracks coding progress for students via LeetCode.

## Role
- Enum for user roles (STUDENT, FACULTY, PLACEMENT_HEAD).

## ShortlistStatus
- Enum for shortlist status (SHORTLISTED, REJECTED, SELECTED, NOT_SELECTED).
