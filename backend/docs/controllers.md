# Controllers Documentation

REST controllers for API endpoints:

- **StudentController**: /api/students (CRUD for students)
- **UserController**: /api/users (CRUD for users)
- **CompanyController**: /api/companies (CRUD for companies)
- **PlacementDriveController**: /api/placementdrives (CRUD for placement drives)
- **ShortlistController**: /api/shortlists (CRUD for shortlists)
- **NotificationController**: /api/notifications (CRUD for notifications)
- **AuditLogController**: /api/auditlogs (CRUD for audit logs)
- **LeetCodeStatsController**: /api/leetcode-stats (CRUD for LeetCode stats)
- **RoleController**: /api/roles (CRUD for roles, enum)
- **ShortlistStatusController**: /api/shortlist-statuses (CRUD for shortlist status, enum)

Each controller provides standard REST endpoints for its entity.
